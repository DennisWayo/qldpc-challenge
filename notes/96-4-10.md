# [[96,4,10]] — weight-5 mixed-monomial bivariate bicycle code

## Direction & hypothesis

Target: the `unrestricted` x `weight-6` (and looser) cells. This code has
maximum check weight 5, one below the `weight-6` ceiling, which is the axis
the existing `[[96,4,12]]` twisted-torus baseline on this board does not beat
it on (that entry has weight-6 checks). The direction was not a fresh search
in this repository but a targeted mining of an already-completed, larger
weight-5 bivariate-bicycle (BB) evolutionary campaign run in a companion
repository, looking for connected presentations small enough, and with strong
enough distance evidence, to submit here directly.

## What was searched

The source campaign (github.com/qiskit-community/qcode-discovery @
51754b5f5628a5cd68b89e6e8ee6d699150afb3a) ran an LLM-guided evolutionary
search (OpenEvolve) over weight-5 mixed-monomial CSS BB polynomial pairs
`(A, B)`, screening candidates by `k = n - rank(H_X) - rank(H_Z)`, CSS
commutation, and a BP-OSD distance estimate, then MILP-verifying standout
candidates exactly. This code is a direct match: a disconnected parent
presentation at `(ell=16, m=12)` with `k=16, n=384` decomposes into 4
identical connected components; one of those components has an explicit small
BB presentation at `(ell=16, m=3)`, `A = 1 + y + x^2y^2`, `B = 1 + x^3`, and
that presentation was matched to the parent via BLISS canonical-form
isomorphism (`evaluation/tanner_equivalence.py` in the source repo), which
transfers the parent's exact distance to the component.

No fresh search ran in *this* repository; the work here was independent
re-verification of an already-found candidate using this repo's own trusted
tools, per `research/AUTORESEARCH.md`.

## Evidence trail

Rebuilt `(H_X, H_Z)` from the polynomials above using this repo's own
`research/kit/bb.py:build_bb`, then re-confirmed every claim independently
with this repo's own tools before submitting:

- `research/kit/css.py:verify_css` / `compute_k` — CSS commutation holds,
  `k = 4` exactly (GF(2) rank), `n = 96`, max check weight 5 on both sides.
- `research/kit/surrogate.py:distance_rand` — randomized upper-bound search at
  5,000 and again at 50,000 trials, both returning `d = 10` (converged).
- `research/kit/distance.py:decoder_distance` — independent BP+OSD mechanism,
  200,000 injected-error trials, `d_heuristic = 10`, `verdict = corroborated`.
- `research/kit/distance.py:exact_distance` (scipy/HiGHS MILP via
  `verify/certify.py`) — proved **exact**: no nontrivial logical lighter than
  weight 10 exists on the X side or the Z side. Wall time 78s at
  `tlim = 600s` (k = 4 solves per side, well inside the envelope described in
  `CONTRIBUTING.md`).

Final claim: **exact**, `d = 10`, certified by this repository's own MILP
solver, not only by the source repository's internal claim.
