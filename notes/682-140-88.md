# [[682,140,88]] - cyclic-ideal generalized-bicycle code

Distance is a witness-backed upper bound (`d <= 88`), not an exact-distance
claim.

## Direction & hypothesis

This entry targets the unrestricted / weight-9plus board. At search time the
score to beat was `1573.977` from `[[682,172,79]]`. After the previous
`[[674,170,82]]` candidate was structurally refuted, the search shifted toward
cyclic generalized-bicycle codes where the strongest known single-block
structural screen still left a board-advancing witness-backed distance.

The surviving candidate is a length-682 cyclic generalized-bicycle code over
`Z_341` with dimension `k = 140` and maximum check weight 31.

## What was searched

The targeted private run swept cyclic generalized-bicycle candidates over
`m = 331,335,341`. For each odd lift it factored `x^m + 1` over GF(2), selected
divisor ideals in the configured degree band, mined sparse words in those
ideals, and paired them with randomized relative shifts.

Pairs were kept only when the polynomial gcd gave the exact designed dimension,
the maximum row weight was at most 32, and a fast randomized witness screen
found a nontrivial logical witness above the target score bar.

## Evidence trail

The submitted file is `codes/682-140-88.json`. It has `n = 682`, `k = 140`,
maximum check weight `w = 31`, and witness-backed upper-bound distance
`d <= 88`, with side witnesses included in the JSON.

The confirmation ladder for this candidate was:

- Raw fast RIS screen found an X logical witness of weight 95.
- A separate snapshot of the top 128 live records was structurally screened
  without interrupting the long-running search.
- A 50000-trial structure-aware circulant GB screen found the submitted
  Z logical witness of weight 88.
- A follow-up 400000-trial structure-aware screen on the corrected `d <= 88`
  claim found no lower structural witness for this candidate.
- `verify/qldpc_verify.py` accepted the packaged JSON, including CSS
  commutation, computed `k = 140`, LDPC check weight, and both distance
  witnesses.
- `verify/validate_candidate.py --refute` passed locally: no exact duplicate,
  no WL-equivalent board warning, and no lighter logical in the local verifier
  refutation pass.

The final score is `140 * 88^2 / 682 = 1589.677`.

## Dead ends

Most higher raw records in the same snapshot collapsed under the deeper
structure-aware screen. The leading `[[662,180,84]]` and `[[662,180,83]]`
records typically dropped to weight 60, while many `[[682,140,95]]` records
dropped to weight 86. This entry is the only above-target survivor from the
400000-trial follow-up over the 50000-trial survivors in that snapshot.

## Tools

The search used the repository verifier stack, `verify/gf2_fast.cpp` for fast
GF(2) randomized witness search, the public circulant-GB structural refuter
proposed in https://github.com/unitaryfoundation/qldpc-challenge/pull/946, and
`verify/validate_candidate.py` for the trusted local gate.

## Reproduction

Let `A` and `B` be length-341 binary circulants over `Z_341`. Use first-row
supports:

`a = [0, 2, 4, 19, 33, 42, 44, 59, 79, 106, 141, 160, 217, 287, 302]`

`b = [5, 18, 35, 47, 56, 66, 94, 154, 211, 254, 290, 292, 305, 312, 335, 338]`

Then build the CSS checks as `H_X = [circ(a) | circ(b)]` and
`H_Z = [circ(b)^T | circ(a)^T]`. The complete parity-check supports and
distance witnesses are recorded in `codes/682-140-88.json`.
